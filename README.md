# Selfless Humanitarian Service - Redesign (v2)

This repository is dedicated to developing the redesigned, modernized version of the **Selfless Humanitarian Service** website to present to the client.

## Live Preview
- **Subdomain:** [https://new.selflesshumanitarianservice.com](https://new.selflesshumanitarianservice.com)

## Tech Stack
- **Framework:** React 18
- **Bundler:** Vite
- **Deployment:** Hostinger Web Apps (`new.selflesshumanitarianservice.com`)

## Development Setup
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Build files will be generated in `dist/`.
